# LM Chat 上手指南（群友版）

## 这是个啥？

一个**小圈子用的端到端加密聊天 App**。说人话就是：你发的消息在手机上就加密了，服务器只是个"邮差"，它只管把加密后的包裹送到，**自己都看不懂里面写了啥**——只有你和对方能解开看。适合聊点不想让第三方知道的事。

## 一、安装（安卓）

1. 找群主要 APK 安装包（一般在群文件里，叫 `lmchat.apk`）
2. 点开安装时，系统会提示"禁止安装未知来源应用"——按提示**允许安装**即可（不同手机叫法不一样，有的在"设置→安全"里）
3. 装好打开就行

## 二、第一次注册

打开 App 后会让你填三样东西：

- **服务器地址**：已经帮你填好了，不用动
- **邀请码**：这个是圈子门禁卡，**找管理员要**
- **昵称**：你想让别人看到的名字，随便起

点注册，成功了你会看到一串 **32 位的「账号ID」**——

> ⚠️ **这就是你的"名片"，复制保存好！**
> 加好友全靠它，别人要加你就把这串发给他。

## 三、加好友聊天

- 把你的账号ID发给对方，或者拿到对方的账号ID
- App 里点「加好友」，粘贴对方ID，备注个昵称
- 然后就能发消息了

## 四、建群

点「建群」，输入群名，然后把要拉的成员账号ID一个个贴进去（逗号或换行分隔）就行。

## 五、安卓保活（重要！）

国产安卓对后台杀得狠，**不设置的话消息会延迟甚至收不到**。给你用的手机做一下：

- **电池/省电策略**：找到 LM Chat → 设为「不限制」/「无限制」
- **自启动**：允许
- **后台锁定**：最近任务里把 LM Chat 锁住（下拉小锁图标）
- 各家叫法不同（小米叫"省电策略"，华为叫"启动管理"，OPPO/vivo 类似），核心就一句话：**别让它被杀后台**

## 六、换手机怎么办？

诚实说：

- **聊天记录存在手机本地，换机不迁移**，新手机上是空的
- 在新手机上用同一个邀请码重新注册，会得到**新的身份**（账号ID也变了），得让朋友重新加你
- 所以：**账号ID和聊天记录，换机前该截图截图，该导出导出**

## 七、常见问题

**Q：消息收不到 / 半天才收到？**
九成是后台被杀了。看上面第五条做保活设置；再不行杀掉 App 重开，它会自动补拉漏掉的消息。

**Q：图片发出去对方加载慢？**
图片是加密后上传的，第一次传大图会慢一点，属正常。等一下就好。

**Q：忘记昵称 / 账号ID 了？**
打开 App，会话列表顶部就写着你的ID，点一下就能复制。

**Q：能发多大图？**
单张别超过 20MB，太大传不动。
